User Guide

이용 안내

프로그램에 문제가 생겼을 때 요청을 남기고, 처리 상태를 확인하는 방법이에요.

1. 요청 남기기 2. 내용 쓰기 · 캡처 붙여넣기 3. 접수번호 받기 4. 회원가입 · 로그인 5. 처리 상태 보기 6. 유료 작업 동의 7. 자주 묻는 것

01요청 남기기

  1. 담당자에게 받은 회사 전용 링크를 열어요. 회사 이름이 자동으로 들어가 있어요.
  2. 전용 링크가 없으면 첫 화면에서 회사 이름을 직접 적고 요청할 수 있어요.
  3. 이름, 이메일(꼭 필요), 전화번호(적지 않아도 돼요), 프로그램 이름을 적어요.
  4. 요청 종류(오류 · 수정 요청 · 사용 문의)와 급한 정도(보통 · 급함 · 업무 중단 중)를 골라요.

요청은 로그인하지 않아도 남길 수 있어요.

02내용 쓰기 · 캡처 붙여넣기

  1. 무슨 일이 있었나요? 칸에 상황을 적어요. 언제부터, 어느 화면에서, 무엇을 눌렀을 때 생기는지 적어 주면 빨리 확인할 수 있어요.
  2. 화면을 캡처한 뒤 내용 칸에서 Ctrl+V를 누르면 글 사이에 그림이 들어가요. 이미지 넣기 버튼으로 골라 넣어도 돼요.
  3. 엑셀 · 문서 · 로그 같은 파일은 파일 첨부 버튼으로 붙여요.
  4. 아래 동의 칸에 체크하고 요청 보내기를 눌러요.
  • 그림은 5장까지, 첨부파일은 5개까지 넣을 수 있어요. 파일 하나는 10MB까지예요.
  • 같은 회사에서 최근에 남긴 비슷한 요청이 있으면 내용 칸 아래에 알려 드려요. 이미 접수된 건이면 다시 보내지 않아도 돼요.
  • 짧은 시간에 여러 번 보내면 잠시 막혀요. 조금 뒤 다시 보내 주세요.

계정 · 비밀번호 · 주민등록번호 같은 민감한 정보는 적지 마세요. 캡처에 보이지 않는지도 확인해 주세요.

03접수번호 받기

보내면 바로 접수번호가 나와요(예: C001-2026-0004). 전화나 메일로 물어보실 때 이 번호를 알려 주세요.

04회원가입 · 로그인

처리 상태를 보려면 회원가입이 필요해요. 회사 전용 링크에서 가입하거나 로그인하면, 그 회사가 남긴 요청을 모두 볼 수 있어요.

  1. 전용 링크 화면의 이 링크에서 회원가입을 눌러요.
  2. 이메일과 비밀번호(8자 이상)를 적고 가입하기를 눌러요.
  3. 확인 메일이 오면 메일 안의 링크를 누른 뒤 로그인해요.

비밀번호를 잊으면 로그인 화면의 비밀번호를 잊었어요를 눌러 새로 정할 수 있어요.

05처리 상태 보기

로그인한 뒤 위쪽 메뉴의 내 요청 내역을 눌러요.

상태뜻
접수됨요청이 들어왔고 담당자가 확인하고 있어요.
처리 중담당자가 작업하고 있어요.
확인 필요잠시 멈춘 상태예요. 자료나 답변이 필요하면 연락드려요.
완료처리가 끝났어요.

06유료 작업 동의

비용이 드는 작업이면, 시작하기 전에 예상 작업 시간과 내용을 먼저 보내 드려요. 내 요청 내역에서 확인하고 골라 주세요.

07자주 묻는 것

링크가 맞지 않다고 나와요.
링크가 바뀌었거나 더 이상 쓰지 않는 링크예요. 담당자에게 새 링크를 받아 주세요.
내 요청 내역에 요청이 안 보여요.
회사 전용 링크에서 로그인해야 회사 요청이 모두 보여요. 링크 없이 가입했다면 전용 링크를 연 뒤 다시 로그인해 주세요.
탈퇴는 어떻게 하나요?
내 요청 내역 맨 아래 회원 탈퇴에서 비밀번호를 넣으면 바로 지워져요. 이미 남긴 요청은 처리를 위해 개인정보 처리방침의 보관 기간 동안 남아 있어요.
요청은 얼마나 보관되나요?
처리가 완료된 날부터 1년 뒤 자동으로 지워져요.
