## 설계도(PRD)에 있던 것 → 만든 상태
| PRD 항목 | 상태 |
|---|---|
| 첫 화면: 한 문장 + 버튼 + 안내 세 줄 | 만듦 |
| 요청 폼: 회사·이름·연락처·프로그램·종류·급한 정도·내용·캡처(3장)·동의 | 만듦 (캡처는 PC에서 Ctrl+V도 됨) |
| 접수 완료 화면 + 접수 번호 | 만듦 |
| 문의 저장(Supabase) + /admin | 만듦 |
| 회원가입·로그인·내 요청 내역 | 만듦 — **실제 가입은 아직 아무도 시험하지 않음** |
| 개인정보 처리방침 | 만듦 (보관 기간·담당자·시행일까지 채움) |
| 분위기: 깔끔한 | → 2026-10-11에 **에디토리얼 스타일로 바꿈** (아래 "디자인") |
| 프로그램 목록 | 사용자 결정으로 "직접 적는 칸" 유지 |
| 답변 시간 | 아직 안 정함 → "확인 후 연락드려요"로만 표시 |

## 고객사 전용 링크 (2026-10-11 추가)
- **관리자 → [고객사] 탭**에서 회사를 추가하면 전용 링크(`사이트주소/r/코드12자리`)가 생긴다. [링크 복사] → 카톡·문자로 보내기
- **전용 링크로 들어오면**: 회사 이름이 자동으로 들어가고 바꿀 수 없다. 요청은 로그인 없이 남길 수 있고, 관리자 요청함에 **"고객사"** 표시
- **링크 없이 첫 화면으로 들어오면**: 회사 이름을 직접 적는 폼. 요청은 **"신규 문의"** 표시로 따로 모인다
- 관리자 요청함 **[구분: 전체 / 고객사 / 신규 문의]** 필터. 신규 문의 카드의 **[고객사로 등록]** → 고객사가 만들어지고 같은 회사 이름의 신규 문의가 함께 묶인다
- **내역 보기는 로그인해야**: 전용 링크에서 회원가입·로그인하면 그 계정이 고객사에 자동 연결 → "내 요청 내역"에서 **그 회사 요청 전부**를 본다. (고객사에 연결 안 된 계정은 본인이 로그인하고 남긴 요청만)
- [링크 새로 만들기]: 예전 링크는 바로 못 씀 / [사용 중지]: 그 링크로는 요청 불가
- 회원 탭에 회원별 연결된 회사가 보인다. CSV에 "구분" 칸 추가

## PRD에 없었는데 나중에 더한 것 (관리자 화면 중심)
48시간 알림 · 30일 추이 그래프 · 상태별 보기 · 검색 · 메모 · CSV(목록·변경 기록) · 요청 수정 · 변경 기록(내용·상태·메모)과 종류 필터 · 요청 삭제(한 건·여러 건) · 회원 탭(요청 수, 회원별 요청 보기) · 회원 탈퇴 · 완료 후 1년 자동 삭제(매일 새벽 4시쯤)

→ 처음 설계도는 "1~3장짜리 접수 사이트"였는데, 관리자 화면이 가장 커졌다. PRD를 다시 쓴다면 **관리자 화면에서 정말 매일 쓰는 것**을 먼저 고르는 게 좋다.

## 디자인 (지금 적용된 기준)
- 바탕 #f7f6f2 · 글자 #1c1c1c · 강조 #3d7068 · 선 1px #e5e4de · 모서리 각지게
- 제목: Playfair Display + Noto Serif KR(한글, 가는 굵기) / 본문: Space Grotesk + Pretendard / 라벨·숫자: Space Mono(영문 대문자, 넓은 자간)
- 40px 격자 배경(가장자리로 흐려짐), 움직임 곡선 cubic-bezier(0.16, 1, 0.3, 1) — 처음 열릴 때 0.9초, 버튼 반응 0.3초
- 상태 색: 새 요청 = 청록(#3d7068), 처리 중 = 황토(#a5701a), 완료 = 회색(#55554f), 업무 중단 = 붉은색(#9b2c1f)
- 스타일 파일은 하나: assets/style.css (관리자 화면만 자기 전용 스타일이 조금 더 있음)

## 사용자가 직접 해야 남은 일
1. **Supabase 로그인 설정** (회원가입을 쓰려면 꼭 필요): Vercel → Storage → supabase-coquelicot-castle → Open in Supabase → Authentication → URL Configuration → Site URL에 사이트 주소 → Save
2. (시험할 때만) Sign In / Providers → Email → Confirm email 끄기
3. 고객사를 하나 등록하고 그 **전용 링크에서 가입 → 로그인 → 요청 → 내 요청 내역(회사 요청이 보이는지) → 탈퇴**를 한 번 해 보기 (계정 만들기는 Claude가 대신 못 함)
4. 전화번호 010-1234-5678이 실제 번호인지 확인 (예시 번호처럼 생김)

## 알아 둘 것
- 관리자 화면은 최근 500건까지 불러온다 (검색·CSV도 그 안에서)
