# 지금까지 만든 것 정리 (2026-10-11, 접수 대장 v2)

설계도(docs/PRD.md v2)와 실제로 만든 것을 나란히 적었다.

## 주소
- 사이트: https://maintenance-request-sable.vercel.app
- 관리자: https://maintenance-request-sable.vercel.app/admin
- 코드: https://github.com/parkes-ai/maintenance-request (main에 올리면 Vercel이 자동 배포)
- 화면 캡처: docs/design/ (v2 이전 화면)

## 고객이 보는 화면
| 기능 | 상태 |

| 제출 제한: 전용 링크 1분 3건·1시간 20건 / 링크 없음 10분 3건 / 파일 올리기 10분 40개 | 만듦 |

| 개인정보 처리방침: 이메일·전화·이미지·첨부·IP 변환값, Resend 추가 | 고침 |

## 관리자 화면 (탭: 요청함 · 요청 등록 · 고객사 · 직원 · 월별 정리 · 회원)
- **상태 5가지**: 새 요청 → 배정 → 처리 중 → 보류(이유 필수) → 완료. 담당자를 고르면 자동으로 "배정"
- **처리 패널**: 우선순위(긴급·보통·낮음) · 유형(고장·일반 요청·기능 변경) · **원인(우리 프로그램 오류 / 사용법 안내 / 추가 요청 / 고객 PC·환경)** · 담당자 · 청구 방식(이 요청만)
- **답변 기한**: 평일 9~18시 기준 긴급 2시간, 보통 9시간, 낮음 27시간(업무 시간 3일). 넘으면 빨갛게 표시
- **작업 기록**: 날짜·방식(원격/방문/개발/전화·메일)·시간·내용·담당자를 여러 번 나눠 입력 → 합계가 처리 시간
- **완료 조건**: 처리 시간이 있고 원인을 골라야 완료할 수 있음. 완료하는 순간 요청자에게 **완료 메일** (메일 설정 전에는 "설정 전"으로만 기록)
- **유료 작업 사전 승인**: 예상 시간·내용을 보내면 고객이 내 요청 내역에서 동의/거절 → 기록이 남음
- **요청 등록**: 전화·이메일로 받은 요청을 직접 입력(받은 방법 표시)
- **고객사 선택 칸**: 이름·코드로 찾기 + 목록에서 고르기 (관리자 화면에만)
- **고객사 탭**: 코드(자동 C001…) · 청구 방식(무료/건별/시간당/월 정액/계약에 포함) · 월 정액 포함 시간 · 담당자 연락처 · 계약 범위 메모 · 전용 링크
- **직원 탭**: 직원 추가 · 퇴사 처리(지난 기록은 남음)
- **월별 정리**: 고객사별 건수 · 처리 시간 · 무료로 처리한 시간 · 원인/유형별 · 답변 기한 지킨 비율 · 승인 현황 → **월 응대 보고서**(인쇄·PDF 저장)
- 그 밖에(예전부터): 48시간 알림 · 30일 추이 · 검색 · 메모 · CSV · 수정 · 변경 기록 · 삭제 · 회원 탭

## 사용자가 직접 해야 남은 일
1. **Supabase 로그인 설정** (회원가입을 쓰려면 꼭 필요): Vercel → Storage → supabase-coquelicot-castle → Open in Supabase → Authentication → URL Configuration → Site URL에 사이트 주소 → Save
2. **완료 메일을 쓰려면**: 내 도메인 준비 → Resend 가입 → 도메인 인증 → Vercel 환경변수 `RESEND_API_KEY`, `MAIL_FROM`(예: `알림 <no-reply@내도메인>`) 넣고 다시 배포
3. **고객사 정리**: 고객사 탭에서 회사마다 청구 방식 넣기 (코드는 C001처럼 자동으로 붙음)
4. 고객사 전용 링크로 **가입 → 로그인 → 이미지·파일 넣어 요청 → 내 요청 내역 → 탈퇴**를 한 번 해 보기 (계정 만들기는 Claude가 대신 못 함)
5. 전화번호 010-1234-5678이 실제 번호인지 확인 (예시 번호처럼 생김)

## 알아 둘 것
- 관리자 화면은 최근 500건까지 불러온다 (검색·CSV도 그 안에서)
- 올렸지만 요청에 쓰이지 않은 파일은 하루 뒤 자동 삭제. 완료 후 1년 지난 요청은 파일까지 매일 새벽 4시쯤 삭제
- 삭제는 휴지통 없이 바로 지워진다
- Vercel 무료 요금제는 서버 기능 12개까지 — 지금 10개 사용
- 표 구조와 바꾼 이력: docs/setup.sql
