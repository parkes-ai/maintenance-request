Admin Guide

관리자 사용법

요청을 받고, 처리하고, 달마다 정리하는 방법이에요. 그림은 예시 데이터로 찍었어요.

1. 들어가기 · 로그아웃 2. 요청 목록 보기 3. 요청 처리하기 4. 상태 바꾸기 · 완료 5. 유료 작업 동의 받기 6. 고치기 · 지우기 · 기록 7. 전화 · 메일 요청 넣기 8. 고객사 관리 9. 직원 관리 10. 월별 정리 · 보고서 11. 회원 12. 알아 둘 것

01들어가기 · 로그아웃

  1. 사이트 주소 뒤에 /admin을 붙여 열어요.
  2. 관리자 비밀번호를 넣고 들어가기를 눌러요.
  3. 자리를 비울 때는 오른쪽 위 로그아웃을 눌러요. 탭을 닫아도 로그아웃돼요.

비밀번호는 관리자 화면에서 바꿀 수 없어요. Vercel → 프로젝트 → Settings → Environment Variables에서 ADMIN_PASSWORD를 고친 뒤 Deployments에서 Redeploy를 눌러야 적용돼요.

02요청 목록 보기

  • 48시간 알림: 이틀 넘게 손대지 않은 새 요청이 있으면 빨간 줄이 떠요. 모아 보기를 누르면 그것만 보여요.
  • 상태 숫자: 새 요청 · 배정 · 처리 중 · 보류 · 완료를 누르면 그 상태만 보여요. 전체 보기로 되돌려요.
  • 검색: 접수번호 · 회사 · 이름 · 이메일 · 전화 · 내용 · 메모로 찾아요.
  • 구분: 고객사(전용 링크로 들어온 요청) / 신규 문의(링크 없이 들어온 요청).
  • 엑셀로 받기: 지금 보이는 목록이나 변경 기록을 파일로 받아요. 개인정보가 들어 있으니 보관에 주의하세요.

답변 기한은 평일 9~18시만 세요. 우선순위가 긴급이면 2시간, 보통이면 9시간, 낮음이면 27시간(업무 시간 3일)이에요. 넘기면 빨갛게 표시돼요.

03요청 처리하기

카드의 처리 줄을 누르면 처리 칸이 열려요. 고르는 즉시 저장돼요.

칸쓰는 법
우선순위긴급 · 보통 · 낮음. 바꾸면 답변 기한이 다시 계산돼요.
분류고장 · 일반 요청 · 기능 변경
원인우리 프로그램 오류 · 사용법 안내 · 추가 작업 · 고객 PC·환경. 완료하려면 꼭 골라야 해요.
담당자직원을 고르면 상태가 자동으로 배정이 돼요.
청구 방식 (이 요청만)보통은 "회사 설정대로". 이 요청만 다르게 청구할 때 골라요.
실제 청구 방식자동으로 정해져요. 원인이 "우리 프로그램 오류"면 무료예요.

작업 기록

작업할 때마다 날짜 · 방식(원격 · 방문 · 개발 · 전화·메일) · 분 · 내용 · 작업한 직원을 적고 기록 추가를 눌러요. 여러 번 나눠 적으면 합계가 그 요청의 처리 시간이 돼요. 잘못 적었으면 지우기를 눌러요.

04상태 바꾸기 · 완료

카드 아래 버튼으로 상태를 바꿔요. 고객에게는 오른쪽 말로 보여요.

관리자 화면뜻고객 화면
새 요청막 들어온 요청접수됨
배정담당자를 정함접수됨
처리 중작업하는 중처리 중
보류잠시 멈춤. 이유를 꼭 적어요(예: 고객 자료 대기)확인 필요
완료끝남. 작업 기록과 원인이 있어야 누를 수 있어요완료

완료를 누르면 요청자에게 완료 메일이 가요. 단, 메일 설정(Resend)을 마친 뒤부터예요. 그 전에는 카드에 "완료 메일 설정 전"으로만 남아요.

05유료 작업 동의 받기

  1. 처리 칸 아래 유료 작업 동의에 예상 시간(분)과 무슨 작업인지 적어요. 이 내용은 고객에게 보여요.
  2. 동의 요청 보내기를 눌러요.
  3. 고객이 내 요청 내역에서 진행 동의 또는 동의하지 않음을 누르면 결과와 시각이 남아요.
  4. 잘못 보냈으면 답이 오기 전에 요청 취소를 눌러요.

06고치기 · 지우기 · 기록

  • 메모: 카드의 메모 칸에 적고 저장. 고객에게는 안 보여요.
  • 수정: 회사 · 이름 · 연락처 등을 고쳐요. "관리자 수정"으로 표시되고 기록에 남아요.
  • 고객사로 등록: 신규 문의 카드에 있어요. 누르면 고객사가 만들어지고 같은 회사 이름의 신규 문의가 함께 묶여요.
  • 변경 기록 보기: 상태 · 처리 · 메모 · 내용이 언제 어떻게 바뀌었는지 보여요.
  • 요청 삭제: 첨부와 작업 기록까지 지워지고 되돌릴 수 없어요. 카드의 체크 칸으로 여러 건을 골라 한꺼번에 지울 수도 있어요.

07전화 · 메일 요청 넣기

요청 등록 탭에서 받은 방법(이메일 · 전화 · 기타)과 회사를 고르고 내용을 적어요. 회사 칸에 이름이나 코드를 치면 등록된 고객사가 나와요. 목록에 없는 회사를 적으면 신규 문의로 들어가요.

08고객사 관리

  1. 고객사 탭에서 회사 이름 · 청구 방식 · 월 정액 포함 시간(월 정액일 때)을 적고 고객사 추가를 눌러요.
  2. 코드(C001, C002 …)는 자동으로 붙어요. 접수번호 앞자리가 돼요.
  3. 링크 복사를 눌러 고객사 담당자에게 카톡 · 메일로 보내요.
  • 정보 고치기: 이름 · 청구 방식 · 담당자 연락처 · 계약 범위 메모를 고쳐요.
  • 링크 새로 만들기: 링크가 밖으로 퍼졌을 때 써요. 예전 링크는 바로 못 쓰게 되니 새 링크를 다시 보내 주세요.
  • 사용 중지: 거래가 끝난 고객사. 그 링크로는 요청을 남길 수 없어요. 다시 사용으로 되돌릴 수 있어요.
  • 회사 이름을 누르면 그 고객사 요청만 모아 보여요.
청구 방식뜻
무료돈을 받지 않아요
건별요청 한 건마다 청구
시간당처리 시간만큼 청구
월 정액매달 정해진 금액. 포함 시간을 넘으면 월별 정리에서 빨갛게 보여요
계약에 포함계약 금액 안에 들어 있어요 (무료로 셈)

09직원 관리

직원 탭에서 이름 · 이메일 · 전화 · 가능한 시간을 적고 직원 추가를 눌러요. 직원은 사이트에 로그인하지 않고, 요청의 담당자로 고르기만 해요.

그만둔 직원은 퇴사 처리를 눌러요. 지난 기록은 남고 담당자 목록에서만 빠져요.

10월별 정리 · 보고서

  1. 월별 정리 탭에서 달을 고르고 보기를 눌러요.
  2. 고객사마다 접수 건수 · 처리 시간 · 무료 처리 시간 · 원인별 · 분류별 숫자와 기한 안에 답변한 비율이 나와요.
  3. 월 응대 보고서 보기 → 인쇄 · PDF로 저장을 누르면 고객사에 보낼 보고서가 만들어져요.

요청이 들어온 달 기준이에요. 처리 시간을 나중에 적으면 지난달 숫자도 바뀌니, 보고서는 작업 기록을 다 적은 뒤에 뽑아 주세요.

11회원

회원 탭에서 가입한 고객 담당자, 연결된 회사, 남긴 요청 수를 봐요. 이메일을 누르면 그 회원의 요청만 보여요. 회원을 지우거나 비밀번호를 바꾸는 일은 Supabase 화면(Authentication → Users)에서 해요.

12알아 둘 것

  • 관리자 화면은 최근 500건까지 불러와요. 검색과 엑셀도 그 안에서 해요.
  • 완료된 지 1년 지난 요청은 첨부까지 매일 새벽 4시쯤 자동으로 지워져요.
  • 지운 것은 휴지통 없이 바로 사라져요.
  • 고객 화면에는 우선순위 · 담당자 · 처리 시간 · 원인 · 청구 · 메모가 보이지 않아요.
